# Example: E-commerce refund for used item sold as new

## User scenario

I bought a laptop from an online marketplace. The listing said it was new. When it arrived, the box was resealed, the laptop had scratches, and the battery cycle count was over 300. The seller says this is normal warehouse handling and refuses a refund. I want a refund or replacement. I have photos, the listing screenshot, and the support chat.

## Desired output

Use `complaint-handler` and `angle-finder`.

Expected angle:

- Not as described.
- New item representation contradicted by condition evidence.
- Clean evidence packet.
- Escalate to marketplace buyer protection if seller refuses.

## Suggested first ask

Full refund or replacement with a genuinely new unit, plus prepaid return label.
