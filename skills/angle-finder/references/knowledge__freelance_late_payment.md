# Freelance Late Payment and Scope Creep

## Common patterns

- Client pays late.
- Client keeps adding scope.
- Client delays feedback and blames the freelancer.
- Client disputes work after using it.
- Client asks for a discount after approval.
- Client refuses final payment.
- Client wants source files before paying.
- Client changes decision-makers mid-project.

## Evidence checklist

- Proposal.
- Contract or statement of work.
- Invoice.
- Payment terms.
- Scope definition.
- Change requests.
- Approval messages.
- Delivery timestamps.
- Feedback history.
- Client use of deliverables.

## Strategy

Separate three issues:

1. What was agreed.
2. What changed.
3. What is owed now.

Do not argue feelings. Re-anchor to scope, approval, and payment terms.

## Late payment template

```text
Hi [Name], I am following up on invoice [number] for [amount], originally due on [date].

The work covered by this invoice was delivered on [date] and matches the agreed scope: [brief scope].

Please confirm payment by [date]. If there is an administrative issue, send the expected payment date today so I can update my records.
```

## Scope creep template

```text
Happy to help with that. It is outside the original scope, so I can handle it as an add-on.

Option A: Add [new work] for [price] and extend the timeline to [date].
Option B: Keep the original budget and swap it for [existing item removed].

Which option works better?
```

## Work pause template

```text
I want to keep the project moving, but I cannot continue new work while invoice [number] remains overdue. Once payment is received, I can restart with [next step].
```

## Client discount pressure

If the client asks for a discount after approval:

```text
I understand budget pressure, but the price was based on the agreed scope and the work has already been delivered. I am open to discussing a reduced scope for future work, but I cannot discount completed approved work retroactively.
```

## Saul angle

Do not chase the money like you are asking for a favor. Treat it like a file that needs closing: invoice, due date, delivered scope, next consequence.
